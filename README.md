# AWS Serverless Salary Analytics Pipeline

## Project Overview

SalaryStream is a serverless data processing project built using AWS services and Python. It automatically processes employee salary data when a CSV file is uploaded to Amazon S3.

The AWS Lambda function reads the employee data, calculates the total salary for employees in India and the US, and stores the result in an S3 object named `agg`.

## AWS Services Used

- **Amazon S3:** Stores employee CSV files and the output.
- **AWS Lambda:** Automatically executes the Python function when a file is uploaded.
- **AWS IAM:** Manages permissions for the Lambda function.
- **Amazon CloudWatch:** Stores execution logs and helps monitor the function.

## How It Works

1. An employee CSV file is uploaded to an Amazon S3 bucket.
2. The S3 event triggers the Lambda function.
3. Lambda reads the CSV file using Python and Boto3.
4. The function separates salary values based on employee location.
5. It calculates the total salary for India and the US.
6. The calculated result is saved in S3 as `agg`.
7. CloudWatch logs are used to monitor the execution and troubleshoot errors.

## Input Data

The input file is a CSV containing employee information, including salary and location.

The Lambda function uses the salary and location columns to calculate the totals.

## Output

The function saves the salary aggregation result in an S3 object named `agg`.

Example output format (illustrative only; actual totals depend on the input data):
